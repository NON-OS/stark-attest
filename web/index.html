Verify the NONOS kernel's proof. Here. Now.

This page runs the operating system's own attestation gate, compiled to WebAssembly, against the shipping kernel's STARK trailer. Transparent, post-quantum, no trusted setup. Nothing is sent anywhere: the proof verifies in your tab.

The wasm is the deployment's gate, not a demo: the same verify_attestation_trailer the kernel runs at every process spawn and the bootloader runs before the jump, built from NON-OS/stark-attest with cargo build --target wasm32-unknown-unknown -p stark-attest-verifier-wasm. The trailer binds the kernel's BLAKE3 measurement and the caller context into the STARK transcript; the root is the 32-byte statement the boot chain enforces. Flip any bit of the proof and the gate refuses it, which you can do yourself with the red button. To check the kernel hash against a release, download the image and run b3sum.
