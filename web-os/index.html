what this verifies

Each row is a STARK proof that a specific binary, identified by its BLAKE3 measurement, is an enrolled member of the set the policy root commits to, bound to the exact capability mask that binary was granted. The verifier is the same verify_attestation_trailer the kernel runs before it spawns a capsule and the bootloader runs before it jumps to the kernel, compiled to 90 KB of WebAssembly from NON-OS/stark-attest.

Verifying here proves the proof is valid under this root for these capabilities. It does not prove the binary you run is this one; that link is the measurement, which you reproduce with b3sum against the image. A capability shown as granted is one the proof itself binds, not a claim in a config file.

the parameters

Width-8 Poseidon, 32 rounds, x^7 S-box; FRI with 32 queries, 16 grinding bits, blowup of 4 bits; a depth-8 policy tree. Constants derived from a public rule and re-checked in CI, soundness published under both the provable and the conjectured model. No elliptic curves, so the whole thing is post-quantum by construction.
