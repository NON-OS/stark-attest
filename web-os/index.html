what a green verdict proves

The wasm is not a demo. It is the same verify_attestation_trailer the kernel runs before it spawns a capsule and the bootloader runs before the jump, built from NON-OS/stark-attest. Contexts are rebuilt from the values on this screen, so what verifies is exactly what you read: the measurement, the capability mask, the epoch. A served file cannot bind anything else.

It does not prove the binary you run is this one. That link is the BLAKE3 measurement, which you reproduce with b3sum against a release. A capability shown is one the proof itself binds, not a claim in a config file.

the parameters

Width-8 Poseidon, 32 rounds, x^7 S-box. FRI: 32 queries, 16 grinding bits, blowup 4 bits. Depth-8 policy tree. Round constants derived from a public rule and re-derived in CI every push; the diffusion matrix is MDS by theorem, not by search. Soundness published under both the provable floor and the conjectured model. No elliptic curves anywhere, so the whole construction is post-quantum by birth, not by patch.
